# Gate 8 Contextual Teaching Actions — Visual QA

## Desktop

عند إضافة عنصر إلى الدرس يظهر شريط سياقي مباشر أسفل إعداد الدرس. يعرض اسم العنصر وإجراءات عربية قصيرة مثل شرح وتحليل وتدريب وتقييم ومقارنة وتمييز وتحويل إلى نشاط، مع إبقاء الحالات غير المتاحة واضحة بصريًا بدل إخفائها أو الإيحاء بدعم غير مثبت.

## Mobile

يتكدس شريط الإجراءات عموديًا بعد إعداد الدرس، وتبقى الأزرار قابلة للقراءة داخل RTL. تم الحفاظ على أولوية الوضوح وتقليل عدد النقرات دون تحويل اللوحة إلى واجهة تقنية مزدحمة.

## Evidence limits

هذه معاينة static visual فقط. لم يثبت الاختيار الفعلي من canvas عبر touch/stylus، ولم يثبت screen reader أو UI automation أو browser performance. التحويل إلى Activity موثق عقديًا واختباريًا، أما actions الأخرى في هذه الجولة فهي descriptors وإشعارات سياقية bounded وليست محركات تحليل جديدة.

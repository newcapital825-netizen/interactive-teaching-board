# Midad Productization Scope

## Included الآن

تتضمن النسخة الحالية مساحة المعلم العربية RTL، نموذج الدرس والصفحات والكائنات التعليمية، مسارات النشاط ومعاينة الطالب والتقييم الحتمي وقرار المعلم، والحفظ المحلي والتصدير والاستيراد والاستعادة والعرض. كما تتضمن مساعدًا تعليميًا server-side بعقد JSON صارم، مع حالات ثقة ومصدر وقيود ومراجعة معلم، وتحقيقًا صريحًا من provenance يمنع ادعاءات المصدر غير الموجودة.

## Limited ومثبت bounded

المراجع الخارجية هي روابط معلنة للمراجعة البشرية وليست منهجًا مدمجًا أو تحققًا تلقائيًا. أداة الشعر تقيس الأسطر والكلمات والحروف فقط، ولا تحدد البحر ولا تقدم نقدًا أدبيًا. المساعد يعتمد على سياق يقدمه المعلم أو على خدمة النموذج، ويغلق المسار بأمان عند الفشل أو غياب الدليل. التحقق المتصفحي المتاح يغطي Chromium المكتبي وmobile-chromium المحاكى.

## غير مشمول

لا تشمل هذه النسخة محركًا عربيًا عامًا، أو محرك جبر رمزي عامًا، أو OCR، أو تعاونًا آنيًا، أو مزامنة Cloud، أو Billing، أو مكتبة محتوى رسمية، أو اعتمادًا منهجيًا، أو حسابات طلاب مستقلة، أو تحليلًا عروضيًا آليًا، أو قارئ شاشة مُعتمدًا، أو إثبات Touch/Stylus على أجهزة حقيقية.

## قواعد الاعتماد

لا تُقبل إجابة المساعد تلقائيًا بوصفها حقيقة. يظل المعلم صاحب قرار الاعتماد، ويُعرض المصدر والقيود وحالة الثقة، وتبقى النتيجة في حالة مراجعة عندما لا يوجد سياق قابل للإثبات. ولا تُسمى النسخة `Pilot Ready` أو `Release Ready` قبل جلسات بشرية فعلية ومراجعة نتائجها.

# بروتوكول التجربة المغلقة

## الهدف

إثبات وضوح مِداد للمعلم والطالب في مسار محدود، لا قياس منتج عام ولا إعلان جاهزية تجارية. تُنفذ التجربة لاحقًا مع **3 معلمين و5 طلاب** على بيانات تدريبية غير شخصية.

## إعداد الجلسة

يستخدم كل مشارك نسخة التجربة المحددة، مع تنظيف بيانات المتصفح قبل الجلسة وإنشاء درس جديد. يشرح المراقب قواعد السلامة فقط، ولا يشرح أماكن الأزرار أو المصطلحات. تُسجّل الملاحظات دون أسماء أو بيانات شخصية، وبعد موافقة صريحة إذا وُجد تسجيل صوتي أو مرئي.

## سيناريو المعلم

ينفذ كل معلم المسار التالي: إنشاء درس بعنوان وأهداف، إضافة نص وجملة ومعادلة، تحديد الجملة، فتح التحليل، إنشاء نشاط، تجهيز النشاط للطالب، فتح معاينة الطالب، عرض الدرس، حفظه على الجهاز، إعادة التحميل، تصديره، ثم استعادته أو استيراده. يُكرر المسار الرياضي باستخدام `2x + 3 = 11` فقط.

## سيناريو الطالب

ينفذ كل طالب المسار التالي: فتح معاينة النشاط، قراءة التعليمات، قراءة المحتوى، إدخال إجابة عربية أو خطوات رياضية، إرسال الإجابة، قراءة النتيجة والتغذية الراجعة، ثم إعادة المحاولة إذا ظهرت. لا يحصل الطالب على شرح مسبق للواجهة.

## القياس

يُسجّل لكل مهمة `PASS` أو `PARTIAL` أو `FAIL` أو `NOT OBSERVED`، وعدد طلبات المساعدة، ومواضع التردد، وأي رسالة تقنية أو فقد محتوى أو سوء فهم. تُحسب النتائج لكل فئة منفصلة، ولا تُجمع في رقم واحد يخفي الفجوات.

| الفئة | الحد الأدنى للملاحظة |
|---|---|
| وضوح المعلم | إكمال إنشاء الدرس والمحتوى والنشاط والحفظ دون شرح الواجهة |
| وضوح الطالب | فهم المطلوب والإجابة والإرسال والنتيجة والخطوة التالية |
| سلامة المحتوى | بقاء النص والجملة والمعادلة والأنشطة بعد الحفظ والاستعادة |
| اللغة | عدم ظهور مصطلحات هندسية للمستخدم النهائي |
| الأمان | عدم استخدام بيانات شخصية وعدم تجاوز حدود الحالات المثبتة |

## معايير القرار

يصنف المسار `GREEN` إذا أُنجز مستقلًا، و`YELLOW` إذا أُنجز مع تردد أو مساعدة بسيطة، و`RED` إذا تعذر أو نتج عنه سوء فهم متكرر. إذا ظهرت مشكلة فقد بيانات أو نتيجة تعليمية مضللة، تتوقف الجلسة ويُسجّل الأمر كـblocker. لا يُعلن `PILOT READY` قبل اكتمال الجلسات وتحليلها.

## فصل الأدلة

تُحفظ نتائج الجلسات في `HUMAN_PILOT_RESULTS.md` بعد حدوثها فقط. نتائج Playwright وVitest وcheck/build تبقى أدلة آلية منفصلة. لا تُملأ الخانات الفارغة بأرقام تقديرية ولا تُنسب نتائج المتصفح إلى المشاركين.

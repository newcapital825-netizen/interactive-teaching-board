# REAL HUMAN PILOT PROTOCOL

## الهدف

تقييم وضوح مِداد في تجربة مغلقة فقط، لا إعلان جاهزية عامة. تُجرى الجلسات ببيانات تدريبية غير شخصية وبعد موافقة المشاركين على الملاحظة.

## المعلمون — 3 مشاركين

ينفذ كل معلم هذه المهام بالترتيب: إنشاء درس جديد؛ إضافة جملة عربية؛ فتح التحليل؛ تحويل المحتوى إلى نشاط؛ فتح معاينة الطالب؛ مراجعة الإجابة؛ استخدام قرار المعلم؛ حفظ الدرس؛ إعادة تحميله؛ ثم تصديره.

بعد كل مهمة يسجل المراقب: هل اكتملت؟ هل طلب المعلم مساعدة؟ أين توقف؟ وما الذي لم يفهمه؟ لا يشرح المراقب أماكن الأزرار، ويقدم مساعدة السلامة فقط.

## الطلاب — 5 مشاركين

ينفذ كل طالب: فتح النشاط؛ قراءة التعليمات؛ الإجابة؛ إرسال الإجابة؛ قراءة التغذية الراجعة؛ ثم إعادة المحاولة عندما تظهر. يسجل المراقب completion وconfusion وassistance وerrors وretry behavior.

## قاعدة الدليل

لا تُنسب أي نتيجة إلى مشارك لم يستخدم المنتج فعلًا. عند غياب الجلسات يظل التصنيف `Human Validation = NOT VERIFIED`، ولا تُستخدم كلمات `PASS` أو `GREEN` أو `SUCCESS` أو `USABLE` للدليل البشري.

## الإيقاف

تتوقف الجلسة عند فقد درس أو نشاط أو نتيجة أو قرار معلم، أو عند تلف ملف النقل، أو عند ظهور نتيجة تعليمية مضللة. تحفظ الملاحظات دون أسماء أو بيانات شخصية في `HUMAN_PILOT_RESULTS.md` بعد انتهاء الجلسات فقط.

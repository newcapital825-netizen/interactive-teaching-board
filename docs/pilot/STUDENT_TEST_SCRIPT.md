# نص اختبار الطالب

## تعليمات المراقب

اعرض على الطالب معاينة النشاط فقط، ولا تشرح أسماء الحقول أو معنى النتيجة مسبقًا. اطلب منه التفكير بصوت مسموع إن وافق، وسجّل الفهم والتردد وطلبات المساعدة دون تسجيل بيانات شخصية.

## المهمة العربية

اقرأ السؤال عن الجملة، اختر الإجابة المطلوبة، اكتب إجابتك، واضغط **إرسال الإجابة**. اقرأ التغذية الراجعة وحدد ما الذي ستفعله بعد ذلك.

## المهمة الرياضية

اقرأ المسألة `2x + 3 = 11`، اكتب الخطوة الأولى والخطوة التالية والإجابة النهائية، ثم أرسل الإجابة. اقرأ التفسير، وأعد المحاولة عندما يظهر الخيار.

## سجل المراقب

| الرمز | النتيجة | الملاحظة |
|---|---|---|
| S01 فهم التعليمات | PASS / PARTIAL / FAIL | |
| S02 العثور على مكان الإجابة | PASS / PARTIAL / FAIL | |
| S03 إرسال الإجابة | PASS / PARTIAL / FAIL | |
| S04 فهم النتيجة | PASS / PARTIAL / FAIL | |
| S05 فهم التغذية الراجعة | PASS / PARTIAL / FAIL | |
| S06 معرفة الخطوة التالية | PASS / PARTIAL / FAIL | |
| S07 إعادة المحاولة | PASS / PARTIAL / FAIL | |

إذا احتاج الطالب إلى شرح أو تدخل، سجّل ذلك حرفيًا كـ`ASSISTANCE REQUIRED`. لا تعتبر نجاح الاختبار الآلي دليلًا على نجاح الطالب.

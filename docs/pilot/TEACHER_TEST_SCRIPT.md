# نص اختبار المعلم

## تعليمات المراقب

لا تشرح أماكن الأزرار قبل بدء المهمة. اقرأ المهمة مرة واحدة، ثم سجّل ما يفعله المعلم وكلماته ومواضع التردد وطلبات المساعدة. لا تسجل بيانات شخصية في التقرير.

## المهمة العربية

أنشئ درسًا بعنوان **علامات الإعراب**، أضف الجملة `كتبَ الطالبُ الدرسَ.`، حدد كلمة `الطالبُ`، افتح التحليل، ثم أنشئ نشاطًا من المحتوى وافتح معاينة الطالب. بعد ذلك احفظ الدرس، أعد تحميله، وصدّره.

## المهمة الرياضية

أضف المسألة المثبتة `2x + 3 = 11`، افتح الخطوات، أدخل خطوة صحيحة وأخرى تحتاج إلى مراجعة، ثم افتح معاينة الطالب. راجع نتيجة المحاولة، أضف قرار المعلم مع ملاحظة واضحة، وجرب إعادة المحاولة إذا ظهر الخيار.

# القيود المعروفة — مِداد Pilot

## النطاق التعليمي

العربية والرياضيات تعملان ضمن مسارات وأمثلة مثبتة ومحدودة. لا يُعلن دعم Arabic NLP عام، ولا symbolic algebra عام، ولا الكسور العامة أو الأقواس أو التكافؤات غير المثبتة. الحالة غير المدعومة تُحال إلى المعلم ولا تُخمّن.

## البيانات والحسابات

الحفظ الحالي local-first وعلى هذا الجهاز. لا توجد حسابات متعددة المستخدمين أو مزامنة سحابية أو سجل صف مشترك. لذلك يجب عدم إدخال بيانات طلاب حقيقية أو محتوى سري.

## التحقق البشري والأجهزة

Human Validation غير متاحة في هذه الجولة. Touch وStylus وScreen Reader وFull WCAG وReal-device Performance غير متحققة. Mobile Chromium دليل محاكاة متصفح فقط، وليس دليل جهاز لمس حقيقي.

## النقل والاستعادة

التصدير والاستيراد والاستعادة محمية من payload غير الآمن، المفاتيح الخطرة، المعرفات المكررة، والإصدارات غير المدعومة ضمن الاختبارات الحالية. لا يزال ذلك دليلًا bounded، ويجب الاحتفاظ بنسخة الملف يدويًا أثناء أي تجربة.

## الأداء والنشر

الحزمة الرئيسية بعد code splitting تقارب 306 kB في آخر قياس موثق. لا يوجد performance budget رسمي معلن، ولا يُستخدم هذا الإصدار كخدمة عامة منشورة. يجب تشغيله في بيئة التجربة المحددة ومراقبة الأخطاء.

## غير موجود عمدًا

لا توجد AI أو OCR أو Collaboration أو Billing أو Cloud Sync أو Authentication متعددة المستخدمين أو mobile native app. هذه ليست فجوات يجب تعويضها داخل Pilot Readiness الحالي.
